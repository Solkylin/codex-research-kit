# 科研图表交互精修

当任务需要点选对象、拖动排版、反复调整细节，或将多图统一为可编辑终稿时读取。先确定当前图、源码、数据与目标尺寸；已有任务信息足够时直接使用，不固定重新提问。普通代码修改与预览已经能完成的调整直接处理。

## 按后端与修改保存方式选择

| 当前需要 | 使用路线 | 保存和复现 |
| --- | --- | --- |
| Matplotlib/Seaborn 图，保留原脚本并点选调整 | Tavotto 本地浏览器或当前可调用 MCP | 原脚本与项目布局 JSON 一起保留；外观修改在重画后重放 |
| Matplotlib 脚本，希望鼠标修改直接进入普通代码 | Pylustrator 本机启动器 | `File > Save` 更新原 `.py` 中的普通 Matplotlib 代码；回原项目解释器重画 |
| MATLAB 图，需要原生点选和属性修改 | `plotedit`、Property Inspector 与已确认的目标句柄 | 保存 `.fig`；将需要重现的外观修改纳入原脚本或独立样式脚本 |
| 跨后端组图、缩放后字体/线宽一致、SVG/PDF 排版 | Scientific Inkscape 的独立 profile 入口 | 保存可编辑 SVG 与最终 PDF；原绘图脚本及源导出文件同时保留 |

Python 是语言而非绘图库。Plotly、三维或其他自定义绘图库沿其自身工具链处理；Tavotto 与 Pylustrator 不作为任意 Python 图的通用编辑器。当前重点是 Python、MATLAB，不为本流程新增 R 编辑器或大型独立绘图软件。

机器入口、准确版本、解释器与适用的本机测试结果见[科研工具链索引](../../../docs/toolchain-profile.md)。只读取选中工具的使用说明，不同时启动替代编辑器，也不在普通绘图任务中重复安装或升级。

## Tavotto

优先使用当前会话真实可调用的 Tavotto MCP。工具尚未加载或宿主不支持内嵌 UI 时，使用已安装的本地浏览器入口；不因可选画布缺失中断绘图，也不把浏览器窗口称为 Codex 内嵌画布。

仅使用浏览器时，在导出对话框的“规范 / 出版规范”中选择“自由排版（只做技术性检查）”；目标期刊确定后再按项目规范设置。正式图导出在“高级选项”关闭“生成样式检查报告”，选择 PDF/SVG。必要时先切到原图所在画布再切换规范。以下函数名和 `profile_id`、`proof` 是 MCP 参数，不是浏览器启动命令的必填项。

- MCP 可用时，通过当前工具 schema 与 `tavotto_health` 确认所需引擎和工作区。工作区限定为明确项目；不能用用户主目录或盘符根解决授权问题。
- 选择项目实际解释器、运行目录与绘图入口；需要时使用本机启动器的 `--worker-python`。保留原数据路径与执行约定。浏览器/MCP 路线不自动透传任意原命令行参数，也不保证接管 Notebook 活对象；复杂项目可复用已算好的数据建立小型绘图入口。
- 先固定最终物理尺寸再判断字号和线宽。界面可显示缩放后的有效 pt，保存值可能是缩放前的原图 pt。需要沿用原图尺寸时，可先用“原始尺寸”并核对画布与面板缩放；目标尺寸不同则按最终有效值检查，不把原图 pt 与成品 pt 混用。
- 通过 MCP 操作且未指定期刊时显式使用 `profile_id="free-form-v1"`。已指定期刊时按官方指南及项目参数覆盖；工具的默认课题组规范、字体或尺寸不是通用出版要求。提示需要结合实际图判断，不据此擅自改变科学表达。
- `tavotto_apply_overrides` 的 `patches` 是**全量列表**：先取得现有修改，再合并此次变更并完整提交。单条增量会使其他未列出的修改恢复，不能这样调用。模型改图时使用 `summary=true` 取得简短回执，完整状态仅在定位对象或保留既有修改时按需读取，避免反复加载全图 manifest；对象标识以实际返回值为准。
- MCP 修改首先属于当前会话状态，导出 PDF/SVG 不等于已保存可重开的编辑文件。用户需要持久布局或继续拖动编辑时，首次在实际浏览器画布用“另存为新排版”，随后用 `Ctrl+S` 保存；保留项目 `tavottofile/` 中的 JSON、`tavotto_registry.json`、布局引用的基图 PDF/SVG、对应源码与数据，保持其目录关系，通过“排版 → 打开排版”重开验证修改仍在。MCP 与浏览器状态未同步时按现有修改有意迁移，不能仅关闭会话后宣称已持久保存。
- 数据、拟合、单位、尺度和结构性变化回原脚本处理，再刷新项目并核对受影响的外观修改。
- MCP 正式导出使用 `proof=false`，预检过程报告不进入成品目录；按实际返回路径取得导出文件。首次接入、图形结构变化或具体重放疑点时再使用独立重放，不对每次轻微样式调整重复运行完整计算。

## Pylustrator

使用本机已验证并固定上游提交的版本。它与有保存回归的 PyPI 1.3.0 使用相同版本号，不能只按版本号重新安装。启动器从原项目路径运行脚本，保留调用工作目录和参数，不复制项目，也无需在原脚本添加工具导入。

源文件需要正常的 `plt.show()`。先确认文件有版本记录或可恢复副本；编辑器保存会修改原 `.py`。图像导出语句应位于生成的样式代码之后，否则保存的精修只出现在窗口中而没有进入导出结果。

编辑器环境与项目环境分离。额外领域依赖、强制 Agg、自有 Qt 循环或自动关图的脚本需局部适配或使用匹配环境，不为打开编辑器降级科研主环境。对象创建顺序或图形结构改变后复查生成的索引和布局代码。最终用原项目解释器重画，确认不依赖 Pylustrator 也能得到修改结果。

## MATLAB

实际操控会话时加载 `matlab-control`，按当前 MCP 能力连接并确认目标图。保留现有会话、工程、变量及其他图形；仅需要解释或编写代码时不连接。

对已确认的目标图句柄使用 `plotedit(fig,'on')`，对对象使用 `inspect(obj)`；适合时给源码中的关键对象设置稳定 `Tag` 或保留显式句柄，以便将样式修改应用到正确对象。直接在原有图上修改，避免重新计算数据或重新运行耗时仿真。

保存 `.fig` 用于继续编辑，并把需要重现的样式修改纳入原 `.m` 或独立样式脚本。R2024b 原生 Generate Code 在已测简单图上可用，但会遗漏已测 `tiledlayout` 内的内容，不能将它当作复杂组图的唯一源码；此类图沿用原始构图代码和样式修改。不要把测试中的未公开代码生成函数当作跨版本接口。

最终从 MATLAB 导出：PDF 可用 `exportgraphics(...,'ContentType','vector')`；R2024b 的 SVG 使用适用的 `print -dsvg`，不假设其 `exportgraphics` 支持后来版本新增的格式或参数。

## Scientific Inkscape

使用工具链索引中的独立 profile 启动器，菜单为 `Extensions → Scientific`；其扩展由 Inkscape 自带 Python 执行，不用 Anaconda 或科研 venv 替代。该入口只对自身进程设置 profile，不改变用户原 Inkscape 入口。

按图的实际结构选择 Scaler（缩放/恢复字号、刻度和线宽）或 Homogenizer（统一字体、字号和线宽）。导入图需要时先 Flatten，保留必要 clipping/mask，将各面板组织成独立组；避免改变曲线几何、数据或不确定性表达。源脚本修改后重新导出时，应有意重做或迁移排版，不能假定 SVG 修改会回写 Python/MATLAB。

需要编辑文字时先检查 SVG 中仍有文字对象。Matplotlib 可在导出时设置 `svg.fonttype='none'` 保留文字；已经转为轮廓的字体应回源重新导出，不能期望 Homogenizer 从路径恢复原始字体或公式语义。

## 成品检查

在最终尺寸下检查实际 PDF/SVG 与渲染：修改的对象是否正确、字号和线宽是否合理、图例和标签是否遮挡、是否裁切、字体与文字是否按目标格式保留。验证对应的保存方式能复现此次修改，并确认数值数据与误差定义没有因外观精修改变。检查针对本次变化，输入与计算未变时复用既有结果。
