# 原生文件与检查

用于工具选择、可编辑制作、表格定位、导出及实际渲染检查。先确认目标文件与当前可用能力，读取所选格式工具的实际接口。

## 按能力选择路线

| 当前需要 | 路线与专业职责 |
|---|---|
| 本地可编辑 PPTX | 读取当前 `pptx` 的 `SKILL.md`；按模板和对象保真要求选 PowerPoint、python-pptx、PptxGenJS 或可用的原生演示工具 |
| 已打开的演示或原生画布 | 先查看可用文档控制会话或原生制品会话；确有绑定时操作目标文档，无绑定时走文件路线 |
| Google Slides、Canva、Figma Slides、Spaces | 按用户目标与现有文件位置使用相应连接器及平台技能，检查实际输出 |
| 数据图和组图 | 读取 `publication-figures`，沿原 MATLAB、Python 或 R 数据链；实现时再选最窄的绘图技能 |
| 精确结构、机制和信号关系 | 读取 `scientific-schematics`，选原生形状、SVG、Mermaid、Graphviz、TikZ 或相应可编辑工具 |
| 补充说明性位图 | 优先内置官方 `image_gen` 并读取系统 `imagegen`；按用户指定平台或独有能力选已连接图像插件 |
| Beamer 或其他明确指定格式 | 沿项目既有模板与对应工具链制作，检查所交付格式的真实输出 |

只选择会改善本次证据、可编辑性或成品质量的工具，并实际取得相应结果。安装、缓存、认证与可调用状态分别判断。可选能力缺失时继续可行路线；必要能力受阻时准确说明尚缺的结果。CLI/API 图像生成仅在用户明确选择后使用。

## 保留可编辑对象

文字、表格、图注、箭头和关系图使用原生对象或合适的可编辑矢量。真实原图与数据图可以作为图片嵌入；保留其源数据、脚本或原页定位等复现所需内容。整页截图不能替代要求的可编辑演示。

公式优先使用目标应用支持的原生数学对象，或保留清晰矢量与公式源。采用 Office Math 时，可使用本机 Office 的 MathML→OMML 变换；转换后检查分式、根号、帽符号及上下标，不随交付复制 Office 自身专有转换文件。

编辑既有文稿时保持需要的对象、页序、Notes、隐藏状态、关系与引用。重排依据实际 slide relationships，不能把 `slideN.xml` 文件名当作展示页号。使用目标软件导出时保留用户已打开文档，只关闭本次创建的文档或实例。

跨文稿原生合并时检查母版、布局、Notes 和媒体的全局关系。ZIP、XML 或 SDK 校验只说明各自规则覆盖的范围；文件可用性仍由目标应用实际打开、导出与播放确认。

## 拆分与派生的引用

拆讲、重排或派生较短版本时，区分当前稿内部页、另一固定文稿的页和原件物理页。按目标稿的实际页序重建内部链接；未纳入目标稿的内容，用明确的文稿名称与页码定位。原始论文、专利或手册的物理页保持原件定义。

正文和备注除显式页码外，还须逐句核对“前页”“后续案例”“查阅层”等隐式承接，确认目标稿确有相应内容。数字批量替换不能代替此项判断。讲述正文与页码、日期等版式占位符分别提取；重排后另核布局缓存及实际显示，避免将旧页号混入讲稿。

## 原生三线表的实际高度

用原生 table 保存单元格和文字。根据正文、换行与单元格边距设置合理行高；设置值只是生成意图，实际文件与渲染决定表格是否紧凑。

若三线表使用独立线对象，序列化后读取实际表格的顶坐标与各行高度。在 PPTX OOXML 中，以表格 `graphicFrame` 的 `p:xfrm/a:off/@y` 为起点，累加 `a:tbl/a:tr/@h`，在相同 EMU 坐标下得到末行下边界；据此定位表底线。表头下线由表头行的实际高度确定。不要只用名义 frame 高度或预设整体高度推算底线。

修改文字、字号、边距或行高后，重新检查序列化行高与线位置，再查看目标应用的渲染。表格处于缩放或变换容器时应用相应坐标变换。可用表格边框准确实现三线时，优先直接使用边框，减少同步对象。

## 渲染与检查范围

新制作或整体重构先验证包含主要难点的代表页面，例如原图标注、公式、紧凑表格、结构过程和结果图。方法有效后推广，并检查正式成品各页实际渲染。小修检查受影响页面及换行、分页、引用等连带变化；具体疑点才扩大范围。

优先采用当前可用的原生页面导出或目标应用 PDF 导出，再用已安装的 PDF 查看器、PyMuPDF 或其他合适工具检查。没有现成转换脚本时可直接用这些能力；不依赖旧技能目录或把上游示例路径当作项目现有文件。

联系表适合检查页序和整体模式；关键小字、公式、原图标签和三线表底部需要足够大的单页图。核对中文缺字、裁切、遮挡、单位、图轴、表格行高、线位置、颜色含义及阅读顺序，同时比较当前讲稿与实际画面。

修复具体问题后重导出受影响成品并复看变化部分。已有检查在输入、实现与环境未变时按覆盖范围复用；不预设每次小修的全量检查、固定复核轮次或无关测试。记录所看的实际文件与范围，不以脚本退出或对象存在替代可读性判断。
