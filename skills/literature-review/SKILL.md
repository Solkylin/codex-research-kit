# Literature Review

First classify the request as a light narrative review, structured technical survey, systematic review, scoping review, or meta-analysis. Use the full systematic workflow only when the user, protocol, venue, or research question requires it.

## Source workflow

- Define the question, population or system, intervention or method, comparison, outcomes, date range, and source types when applicable.
- Search from the question structure using primary papers, standards, official documentation, datasets, and author or project repositories. Use multiple databases when coverage or protocol requires it.
- Read the actual paper, abstract, table, figure, or official record that supports a claim. Search snippets locate sources but do not establish conclusions.
- Track enough metadata to locate sources and distinguish versions, populations, metrics, and experimental conditions. Do not create a full search log for a normal review unless requested.
- Verify DOI or bibliographic metadata when it affects identity or citation correctness. Do not run blanket citation verification when it cannot change the conclusion.

## Synthesis

Organize by mechanisms, methods, evidence quality, datasets, or engineering tradeoffs rather than by a list of papers. Preserve disagreements, incompatible conditions, null results, and uncertainty. Do not merge metrics from different populations or definitions without explaining the difference.

For systematic reviews, report the search strategy, databases, dates, screening rules, inclusion/exclusion criteria, extraction fields, and synthesis method required by the protocol or reporting guideline. For ordinary reviews, keep the method proportional.

## Output

Use the user's requested format. Figures such as PRISMA diagrams or evidence maps are optional and should be generated only when they clarify the review or are required by the protocol. Keep search logs, tool output, agent coordination, and internal audit language outside the formal review unless the user requests an appendix.
